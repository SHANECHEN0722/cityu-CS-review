## 10:30–13:00｜Input Devices：这是高频核心章

这章不要死背设备型号，要抓：**tracking 原理 + 性能指标 + 设备类型比较**。

### 2.1 Basic of 3D Tracking

必会定义：

- **Tracker**：实时测量物体 position and/or orientation 的设备。
- VR 常追踪：head、hands、limbs。
- 通常相对于 reference / world coordinate system 表示。
- **DOF**：independent motions / measurements 的数量。
  - 2 DOF：mouse
  - 3 DOF：accelerometer / gyroscope
  - 6 DOF：position + orientation，常见于 VR headset/controller

### 2.2 坐标矩阵链

核心公式只需要理解含义：

```text
v2D = Mproj * Mview * Mworld * v3D
```

- `Mworld`：model/local → world
- `Mview`：world → user's view
- `Mproj`：view → 2D image

如果考简答，不一定要推导公式，但要能说清三层变换。

### 2.3 Tracking performance 四指标

| 指标 | 英文解释 | 你要会区分的点 |
|---|---|---|
| Accuracy | measured value close to actual value | 空间误差，常随距离变差，决定 operating range |
| Jitter | output changes even object is stationary | 静止时随机抖动 |
| Drift | error grows over time | 时间累积误差，常需 secondary tracker reset |
| Latency | delay between action and signal/output | 延迟会导致 sickness，如 headache / nausea / dizziness |

#### 常考陷阱

- **Jitter** 是“静止也乱跳”。
- **Drift** 是“时间越久越偏”。
- **Latency** 是“动作和反馈之间有延迟”。
- **Accuracy** 是“测得准不准”。

### 2.4 Tracker types 总表

| Tracker | 原理 | 优点 | 缺点 | 适合怎么考 |
|---|---|---|---|---|
| Mechanical | links + sensorized joints | accurate, small latency, no line-of-sight issue | intrusive, heavy, limited motion, fatigue | 比较题：为什么准但不沉浸 |
| Magnetic | transmitter magnetic field + receiver | lightweight, no line-of-sight restriction | affected by metal, range limitation | AC/DC、metal interference |
| Ultrasonic | time-of-flight of sound | cheap, simple | low update rate, echoes, line-of-sight, air absorption | Tutorial 1 原理题 |
| Optical | cameras + markers / inside-out | high precision, standard mocap | occlusion, calibration, marker ambiguity | Tutorial 3 / AR / mocap |
| Inertial / IMU | gyroscope + accelerometer + magnetometer | small, cheap, high update, good short-term orientation | gyro drift, accelerometer noise, magnetic interference | sensor fusion / reset |
| Navigation/manipulation | 3D mouse, Magellan, MicroScribe | direct manipulation | sensor coupling / calibration / fatigue | 定义型题 |

### 2.5 Magnetic trackers：AC vs DC

必会：

- AC magnetic trackers：changing magnetic field induces eddy currents in nearby metals → distorted magnetic field → accuracy degraded。
- DC magnetic trackers：用 pulsed DC field 试图减轻 eddy current；但仍受 ferromagnetic metals 和 copper 影响。
- Magnetic field strength drops quickly with distance，所以 range 是问题。

### 2.6 Optical trackers：outside-looking-in vs inside-looking-out

- **Outside-looking-in**：摄像机在外面，marker 在用户/物体上。
  - 用多台 camera 捕捉 marker 反射光。
  - 通过多个 2D image positions reconstruct 3D position。
  - 问题：occlusion / ambiguity。
- **Inside-looking-out**：camera/sensor 在用户身上，看环境里的 marker/beacon。
  - 理论工作空间可扩展。
  - 对 orientation changes 很敏感。

### 2.7 IMU

- Gyroscope：angular velocity，短期准确，长期 drift。
- Accelerometer：linear acceleration，长期好，但短期 noisy；位置要 double integration。
- Magnetometer：earth magnetic field，受金属影响。
- IMU：三者结合，互补。

# Day 1 下午：输出设备 + Presence

## 14:00–16:00｜Graphical Displays：视觉系统 + HMD + 显示类型

这章的主线是：**人眼如何感知 3D → VR display 如何欺骗人眼 → 会产生什么问题**。

### 3.1 Human Visual System

必会：

- Retina 有 rods 和 cones。
- Rods：night vision。
- Cones：color vision。
  - L-cone：red
  - M-cone：green
  - S-cone：blue
- Fovea：central retina，高分辨率、颜色感知。
- Peripheral area：低分辨率，但对 motion 敏感。

### 3.2 FOV

记住大概数值：

- Each eye：约 150° horizontal，135° vertical
- Both eyes combined：约 180° horizontal
- Binocular overlap：约 120° horizontal

考试里更重要的是意义：

> Larger FOV increases immersion/presence, but needs higher rendering resolution and larger display coverage.

### 3.3 Depth perception

| Near object cues | Far object cues |
|---|---|
| convergence | occlusion |
| accommodation | perspective |
| disparity | haze |
| parallax | surface texture |

重点区分：

- **Convergence**：两只眼睛转向同一近物。
- **Accommodation**：晶状体/睫状肌调焦。
- **Disparity**：左右眼图像位置差。
- **Parallax**：头移动时，近物移动看起来比远物大。

### 3.4 Retina display / visual acuity

- Human eye can resolve about **1 arc minute**。
- 如果要匹配人眼视觉，每只眼大约需要：

```text
(60 * 150°) × (60 * 135°) = 9000 × 8100 pixels
```

考试意义：

> True retina-level VR displays are expensive because wide FOV + high resolution imposes huge rendering and memory cost.

### 3.5 HMD image formation

必会：

- HMD 里的 LCD 很小，lens magnifies the image to a larger virtual image further away。
- Special optics:
  - 让眼睛能 focus on close LCD without fatigue
  - magnify image to fill FOV

### 3.6 Convergence-accommodation conflict

这是高频概念：

- 真实世界：看一个物体时，眼睛 convergence 到该物体，同时 accommodation 到该距离。
- HMD：眼睛 convergence 到虚拟物体的深度，但 accommodation 仍然 focus 在 fixed virtual image plane。
- 两者不一致 → convergence-accommodation conflict。

一句话背法：

> In HMDs, vergence follows the perceived virtual object depth, but accommodation remains on the display/virtual image plane, causing conflict.

### 3.7 Display types

| Display type | 核心特征 | 优缺点 |
|---|---|---|
| HMD | personal immersive display, head tracking | immersive, but weight/FOV/resolution/conflict issue |
| Hand-held display | portable | less immersive |
| Autostereoscopic | glasses-free stereo | reduced horizontal resolution, fixed viewing zone unless active tracking |
| Large-volume display | multiple users, CAVE/wall/dome | natural collaboration, expensive, synchronization/calibration hard |
| Volumetric display | 360° view of volume | special hardware, limited resolution/complexity |

### 3.8 Autostereoscopic displays

必会：

- 用户不戴眼镜也能看到 stereo image。
- 原理：left eye sees left image, right eye sees right image。
- 常用 column-interlaced image：odd/even columns 分别给左右眼。
- 缺点：horizontal resolution reduced by half。
- Passive：固定 viewing zone。
- Active：tracking head motion 解决固定位置问题，但机械结构可能 noise / breakage。

## 16:00–17:30｜Sound and Haptics：音频定位 + 触觉/力反馈

### 4.1 Sound properties

必会：

- Sound is a pressure wave propagating through a medium。
- Air speed about 343 m/s。
- Wave properties:
  - reflection
  - refraction
  - diffraction

### 4.2 Human auditory system

- Pinna 会反射声音，放大/衰减部分频率，帮助判断方向。
- Ear canal 放大 3–12 kHz。
- 人耳可听 20 Hz–20 kHz。
- 对 3–4 kHz 最敏感。

### 4.3 3D sound vs stereo sound

一句话：

> 3D sound changes according to the location and orientation of the user’s head; stereo sound does not truly adapt to head pose in the same way.

### 4.4 Sound localization 三类 cues

| Cue | 用来判断 | 关键机制 |
|---|---|---|
| Azimuth cues | horizontal angle | ITD + IID |
| Elevation cues | vertical angle | pinna filtering; avoids front-back confusion |
| Distance cues | distance | loudness, prior knowledge, motion parallax |

#### ITD vs IID

- **ITD: Interaural Time Difference**  
  声音先到离声源近的耳朵。低频更重要。

- **IID: Interaural Intensity Difference**  
  近耳听到更强，和 head-shadow effect 有关。高频更明显。

### 4.5 HRTF

必会：

- HRTF describes how sound from a source is transformed before reaching a listener’s ear。
- 每个人 HRTF 不同，因为 outer ear 和 torso geometry 不同。
- 用自己的 HRTF 空间识别更好；用别人的 HRTF front-back reversal 会更多。
- Convolution：把 input sound 和 HRTF 结合，让用户觉得声音来自某个方向。

### 4.6 Haptic feedback

先分清两类：

| Type | 中文理解 | 反馈什么 |
|---|---|---|
| Tactile feedback | 触觉反馈 | surface geometry, roughness, temperature, vibration |
| Force feedback | 力反馈 | weight, inertia, resistance, torque, stops/resists motion |

### 4.7 Human haptic sensing

- Skin tactile sensors:
  - Meissner corpuscles
  - Merkel disks
  - Pacinian corpuscles
  - Ruffini corpuscles
- Slow-adapting：Merkel / Ruffini，0–10 Hz，适合 edges / stretch / static force。
- Fast-adapting：Meissner / Pacinian，50–300 Hz，适合 contact force changes / vibration。
- Fingertips discrimination：约 2.5 mm。
- Palm：约 11 mm。
- Proprioception：感知自己身体位置与运动。

## 17:30–18:30｜Sense of Presence：长题和应用题的润滑剂

这章页数不多，但考试价值很高，因为它能和任何应用题组合。

### 7.1 Definition

> Sense of presence is the feeling of being there in a virtual environment.

难点在于：要让 visual, audio, tactile, motion, smell 等感官都相信自己真的在那里。

### 7.2 为什么 presence 难实现？

- Characters / motions not realistic enough
- Missing or incorrect sensory information
- Sensors poorly match human capabilities
- Wires and gadgets worn by user

### 7.3 Sheridan 三个 physical variables / metrics

1. Extent of sensory information：感官通道数量
2. Control of sensors：用户能否改变 sensor input
3. Ability to modify environment：用户能否改变环境

### 7.4 Presence measurement

| Measure | 方法 | 例子 |
|---|---|---|
| Subjective | questionnaire | Witmer & Singer; Steed-Usoh-Slater Likert scale |
| Psychophysical | physical stimulus vs subjective rating | screen resolution / lag time vs presence score |
| Objective | physiological or performance | heart rate, blood pressure, task time |

### 7.5 What increases presence

- High visual quality
- Large FOV
- Low latency
- Head tracking
- Multiple senses: audio, haptics
- Interactivity
- Able to see user’s own body parts

### 7.6 What decreases presence

- Disjoint senses
- High latency
- Poor interactivity
- Cables
- Low quality audio
- Cannot see one’s own body parts

#### Presence 答题模板

```text
Presence means the feeling of being there in a virtual environment. It can be increased by high visual quality, large FOV, low latency, accurate head tracking, multimodal feedback such as audio and haptics, and high interactivity. It can be decreased by sensory mismatch, high latency, poor interaction, cables, low-quality audio, and inability to see one’s own body parts.
```

# Day 1 晚上：Architecture + DVE

> 晚上不要开新资料坑。只做结构化整理和问答。建议 20:00 后只做轻量背诵/自测，不再重写大段笔记。

## 19:30–21:30｜Computing Architectures for VR

### 5.1 VR system architecture 四任务

每一帧 VR 系统要做：

1. Read input devices
2. Update virtual world state
3. Render outputs: graphics, haptics, etc.
4. Feed outputs to output devices

### 5.2 VR engine 需要什么？

- Low computational latency
- Fast graphics rendering
- Haptics rendering

### 5.3 Graphics rendering pipeline

三阶段：

| Stage | 在哪里 | 做什么 |
|---|---|---|
| Application stage | CPU | read inputs, update world, select geometry |
| Geometry stage | GPU | transformations, shading, projection, clipping |
| Rasterizer stage | GPU | primitives → pixel fragments, anti-aliasing, texture mapping |

### 5.4 Geometry stage 重点

- Model transformation
- View transformation
- Shading computation
- Scene projection
- Clipping

#### Shading models

| Model | 原理 | 效果/代价 |
|---|---|---|
| Flat shading | one color per polygon | fast, faceted |
| Gouraud shading | interpolate vertex colors | smoother, may miss highlights |
| Phong shading | interpolate normals then compute lighting per pixel | most realistic, expensive |

#### Phong illumination

不需要会推导，但要知道三部分：

```text
ambient reflection + diffuse reflection + specular reflection
```

- Ambient：环境光
- Diffuse：漫反射，和光线/法线角度相关
- Specular：镜面高光，和反射方向 R、观察方向 V 的夹角有关

### 5.5 Rasterizer stage

核心任务：

- Convert geometry primitives into pixel fragments
- Anti-aliasing
- Texture mapping

#### Anti-aliasing

- 把 pixel 分成 sub-samples。
- 每个 sub-sample 算颜色。
- pixel final color = average。
- 更多 sub-samples → better quality，但计算/内存成本更高。

### 5.6 Pipeline bottlenecks

| 判断 | Bottleneck |
|---|---|
| CPU 100% | CPU-limited / application-stage bottleneck |
| 减少 light sources / polygons 后变快 | transform-limited / geometry-stage bottleneck |
| 降低 resolution / polygons 后变快 | fill-limited / rasterizer-stage bottleneck |

### 5.7 Pipeline optimization

- Application stage:
  - faster CPU
  - more cores
  - faster RAM
  - better compiler
  - clever programming: lower precision, fewer divisions
- Geometry stage:
  - reduce polygons
  - reduce light sources
  - use LoD
- Rasterizer stage:
  - reduce image resolution
  - reduce polygons
  - optimize texture/fragment operations

### 5.8 Haptics rendering pipeline

阶段：

1. Collision detection
2. Force computation
3. Force smoothing
4. Force mapping
5. Haptic texturing

要会解释：

- Collision detection：判断用户/物体是否接触。
- Force computation：根据物理模型算接触力。
- Force smoothing：避免力方向突然变化。
- Force mapping：把计算出的力映射到具体 haptic device。
- Haptic texturing：添加 vibration / surface temperature 等 tactile effects。

### 5.9 Graphics vs Haptics synchronization

重要点：

- Graphics pipeline usually 30–60 fps。
- Haptic force rendering may need around 1 kHz。
- 因为输出频率差别巨大，graphics 和 haptics pipeline 往往需要 decouple，但在 application stage 做同步。

### 5.10 GPU architecture

答题角度：CPU vs GPU。

| CPU | GPU |
|---|---|
| control-heavy | data-heavy |
| few arithmetic units | many parallel arithmetic units |
| optimized for low latency | optimized for throughput / high bandwidth |
| good for branching logic | good for parallel rendering / deep learning |

### 5.11 Distributed VR Architecture

- Distributed VR engine uses two or more rendering pipelines。
- Pipelines can be on one computer, several collocated computers, or remote computers。
- Single-user systems:
  - multiple side-by-side displays
  - LAN-networked computers
- Multi-user systems:
  - client-server
  - peer-to-peer
  - hybrid

### 5.12 Multi-pipeline synchronization

| Synchronization | 解释 | 缺点/特点 |
|---|---|---|
| Software synchronization | application stages start frame together | 不考虑每条 pipeline load 不对称 |
| Frame buffer synchronization | synchronize buffer swapping | 仍可能受 display refresh 影响 |
| Video synchronization | one display master, others slaves | 更底层同步 refresh logic |
| Best method | software + buffer + video combined | 同步更完整 |

## 21:30–22:30｜Distributed Virtual Environments

如果时间紧，这章优先背：**multi-server architectures + latency + rollback + prediction**。

### 9.1 DVE / CVE definitions

- **DVE**：shared virtual environment where remote users interact with virtual objects/tasks through networks。
- **CVE**：supports multiple users performing a task together within the virtual world。
- Examples：virtual museum, online games, Second Life, Metaverse。

### 9.2 Why DVE needs multiple servers

- DVE emphasizes interactivity。
- Users expect instant response。
- Single server must handle all clients, update avatars/objects, distribute update messages。
- When user count grows, server overloads → cannot respond instantly。

### 9.3 Multi-server approaches

| Approach | 原理 | 优点 | 问题 |
|---|---|---|---|
| User partitioning | users assigned to different servers | simple | users on different servers usually cannot interact; like separate DVEs |
| Region partitioning | fixed spatial regions, one server per region | spatial load division; popular regions can be smaller | if unpopular region suddenly becomes popular, still overloads |
| Dynamic partitioning | runtime repartition based on load | adapts to load change | complex; must run regularly; local among neighboring servers due to real-time constraints |

### 9.4 Network latency problem

- Discrete events：time gaps much larger than network delay，latency effect smaller。
- Continuous events：time gaps smaller than network delay，latency serious。
- VR/game interaction 属于 continuous events。

### 9.5 Roll-back

典型场景：A 和 B 同时操作同一对象，消息因 latency 到达顺序不同。

- 常见处理：把先发生的一方视为 winner。
- 另一方机器需要 correct illegal state。
- Roll-back：force object from illegal position back to correct position。

优缺点：

- 保证一致性。
- 但用户可能看到 object “jump back”，影响 realism / presence。

### 9.6 Dead reckoning / motion prediction

核心思路：

- 根据已有位置、速度、加速度预测未来位置。
- 减少 update message 频率和 latency 造成的视觉不连续。
- 问题：prediction error。用户突然改变运动方向时，预测会错，需要 correction。

# Day 2：建模 + 应用 + 套题输出

## Day 2 上午：VR Modeling

这章内容很多，但期末两天策略是：**只抓能和架构/应用组合的部分**。

## 09:00–11:30｜VR Modeling 主干

### 6.1 VR object modeling issues

五类：

1. Geometric modeling
2. Kinematical modeling
3. Physical modeling / interactions
4. Object behavior modeling / intelligent agents
5. Model management

### 6.2 Geometric modeling

| Type | 解释 | 优缺点 |
|---|---|---|
| Polygonal meshes | most popular, triangular meshes computationally efficient | efficient, widely supported, but may need many polygons |
| Splines / parametric surfaces | higher-degree smooth surfaces | smooth, less storage, but more complex |
| Point cloud data | from 3D scanners | captures real objects, needs conversion to mesh/surface |

### 6.3 Object appearance

核心：

- Lighting / shading
- Texture mapping
- Multi-texturing

### 6.4 Local vs global illumination

| Illumination | 原理 | 特点 |
|---|---|---|
| Local illumination | render each object individually, not considering other objects | fast, less realistic |
| Global illumination | considers inter-reflections and shadows among objects | realistic, computationally demanding |

### 6.5 Radiosity

- 一种 global illumination。
- 处理 diffuse inter-reflection。
- Iterative process。
- 更真实，但计算成本高。

### 6.6 Texture mapping

必会：

- Texture like stickers for plastic models。
- Performed in rasterizer stage。
- Maps object coordinates to texture coordinates `(u, v)`。

Advantages:

- Increase realism
- Provide better 3D spatial cues
- Reduce number of polygons → increase frame rate

### 6.7 Multi-texturing / bump mapping

- Multi-texturing：多个 textures 叠加，表现 background, reflectivity, transparency, bump 等。
- Bump mapping：用 normal texture 改变光照效果，让表面看起来有凹凸，但不一定改变真实几何。

### 6.8 Kinematical modeling

核心：描述物体位置、方向、运动。

- Homogeneous transformations combine rotation and translation。
- Moving object 需要随时间更新 position/orientation。
- 和 Input Devices 里的 `Mworld / Mview / Mproj` 可以连接起来。

### 6.9 Physical modeling / collision

高频：

- Without collision detection, realistic interaction is difficult。
- Direct polygon intersection expensive。
- Use bounding boxes for fast approximate collision detection。
- Fixed-size bounding box：faster, less precise。
- Variable-size bounding box：more precise, slower。

### 6.10 Two-stage collision detection

答题模板：

```text
A common solution is two-stage collision detection. First, use approximate bounding box pruning to quickly remove non-colliding pairs. Then, for the remaining candidate pairs, perform slower but more precise pair-wise exact collision detection. This balances speed and accuracy.
```

### 6.11 Collision response

- Surface deformation：接触后表面变形。
- Surface cutting：contact force exceeds threshold → vertex duplicated → twin vertices separate by spring/damper laws → cut enlarges。

### 6.12 Force calculation / smoothing / mapping / haptic texture

重点理解：

- Penetration distance 越大，force 越大，直到 device maximum output force saturation。
- Harder interior：stiffness changes after discontinuity point。
- Force smoothing：避免接触力方向突变。
- Force mapping：把多个 haptic mesh forces 映射到具体 actuator。
- Haptic texture：例如 `Ftexture = A sin(mx) sin(ny)` 表示 vibration pattern。

### 6.13 Behavior modeling

| Component | 解释 |
|---|---|
| Interactive objects | independent behavior, e.g., clock, automatic door |
| Intelligent agents | perception → emotions → behavior → actions |
| Crowd behavior | group-level behavior, guided or autonomous |

Three levels of autonomy:

- Guided
- Programmed
- Autonomous

### 6.14 Model management

为什么重要：maintain interactivity and constant frame rates when rendering complex models。

Techniques:

- Level of detail
- Cell segmentation
- Lighting and bump mapping at rendering stage
- Portals

### 6.15 LoD

| LoD type | 原理 | 问题/优点 |
|---|---|---|
| Discrete geometry LoD | several models, select by distance | simple, but popping |
| Model blending LoD | render two adjacent LoDs in transition zone | reduces popping, more cost |
| Geometric morphing LoD | one complex model, edge collapse / vertex split | smoother, more complex |
| Adaptive LoD | local resolution changes by viewer location/orientation | better quality-cost tradeoff |

### 6.16 Time-critical rendering

定义：

> Finish rendering an image within a given deadline set by the frame rate, maximizing image quality under rendering cost constraints.

核心 trade-off：

```text
image quality vs rendering cost
```

## Day 2 中午：Tutorial 1–5 快速复盘

老师说不会有计算题，所以 tutorial 不要花大量时间推公式。你要掌握“问题为什么这样建模”。

## 11:30–13:00｜Tutorial principles

### Tutorial 1：Ultrasonic tracker

考点：time-of-flight 定位。

- Speakers at known positions。
- Microphones receive sound after different times。
- Distance = time × speed of sound。
- 用两个已知 speaker 到 microphone 的距离，求 microphone position。
- 用两个 microphones 的位置求 tracker orientation。

你只需会讲：

> Ultrasonic tracking estimates distances by measuring sound time-of-flight, then reconstructs position and orientation geometrically.

### Tutorial 2：DC magnetic tracking

考点：magnetic field strength and right-hand rule。

- Infinite straight wire magnetic field magnitude: `B = μ0 I / (2πr)`。
- Magnetometer reading tells distance from wire。
- Two wires → two distance constraints → position。
- Direction by right-hand rule。

概念重点：

- Magnetic field strength decreases with distance。
- Metal interference affects magnetic trackers。

### Tutorial 3：Locating markers with cameras

考点：camera projection + calibration + triangulation。

- 3D point projects to 2D image plane。
- With known focal length/FOV and camera pose, compute image coordinate。
- Camera calibration estimates camera parameters。
- Multiple cameras observing the same marker allow 3D reconstruction。
- Degenerate case：points and camera center collinear / same image coordinate → no unique solution。

### Tutorial 4：Parallax barrier

考点：autostereoscopic display。

- Goal：left eye sees left image; right eye sees right image。
- Parallax barrier blocks light so each eye sees a particular set of pixels。
- Has an optimum viewing position。
- Away from best viewing location:
  - inverse image：right eye sees left image / vice versa
  - blurred / blended zones：one eye sees both images

### Tutorial 5：Marker-based AR

考点：AR pipeline。

General AR pipeline:

1. Initialize a 3D coordinate system associated with physical world。
2. Anchor digital content to desired position。
3. Track camera pose and project digital content using camera parameters。

Marker-based AR advantages:

- Marker provides physical coordinate system。
- Marker detection gives ID and camera pose relative to marker。
- Camera intrinsic parameters are obtained by camera calibration。

ArUco marker:

- Synthetic square marker。
- Wide black border for fast detection。
- Inner binary matrix for ID and error correction。

# 3. 长题答题模板：25 分题靠这个拿分

长题大概率不是单章背诵，而是综合题。你应该用固定结构答。

## 模板 A：Design a VR system for X application

```text
1. Application goal
   - What problem does the VR system solve?
   - Why VR is useful compared with real-world training/practice?

2. Input devices
   - What needs to be tracked? head / hand / tool / body / camera
   - Choose tracker type and justify by accuracy, latency, range, occlusion, intrusiveness.

3. Output devices
   - Visual: HMD / large-volume display / autostereoscopic / monitor
   - Audio: 3D sound if direction/distance matters
   - Haptics: tactile or force feedback if touch/force matters

4. Modeling
   - Geometric model: meshes/splines/point cloud
   - Physical model: collision detection, deformation, cutting, force model
   - Behavior model: state machine / agents / crowd if needed
   - Model management: LoD / texture mapping / portals if scene complex

5. Architecture
   - Graphics pipeline: application, geometry, rasterizer
   - Haptics pipeline if force feedback is needed
   - Bottleneck and optimization
   - Synchronization if multiple displays or haptics are used

6. Presence and usability
   - Increase presence: high visual quality, large FOV, low latency, tracking, multimodal feedback
   - Reduce sickness: low latency, stable tracking, avoid sensory mismatch

7. Trade-offs / limitations
   - Cost, latency, calibration, occlusion, haptic realism, computation, network delay
```

### 示例：Design a VR surgical training system

可以这样答：

- Goal：allow students to practice invasive procedures safely and repeatedly。
- Input：track surgical tools and user hand; optical tracker for precision, but beware occlusion; mechanical/haptic device for tool force。
- Output：stereo visual display/HMD; force feedback through PHANToM-like device; optional 3D audio。
- Modeling：organ geometry by polygon/spline/point cloud; physical modeling for deformation/cutting; collision detection and force computation。
- Architecture：graphics pipeline for rendering; haptics pipeline for collision and force; haptic loop higher frequency than graphics。
- Presence：low latency, accurate tracking, realistic haptics, high visual quality。
- Trade-off：high computation, haptic realism difficult, calibration, cost。

# 5. 最后一晚必须背熟的“一页纸”

## 5.1 VR 总定义

VR = real-time simulation + interaction + multiple sensorial channels。

## 5.2 考试三大主题

Input-output devices + architecture + applications。

## 5.3 Tracking 四指标

Accuracy / jitter / drift / latency。

## 5.4 设备比较

Mechanical accurate but intrusive。  
Magnetic no line-of-sight but metal-sensitive。  
Ultrasonic cheap but low update rate / echoes / line-of-sight。  
Optical precise but occlusion/calibration。  
Inertial small and fast but drift/noise; needs sensor fusion/reset。

## 5.5 Depth cues

Near：convergence, accommodation, disparity, parallax。  
Far：occlusion, perspective, haze, texture。

## 5.6 HMD 问题

Lens magnifies small display to virtual image。  
Convergence-accommodation conflict 是 HMD 的核心视觉冲突。

## 5.7 3D sound

Azimuth = ITD + IID。  
Elevation = pinna filtering。  
Distance = loudness/prior knowledge/motion parallax。  
HRTF is personal; wrong HRTF increases front-back reversal。

## 5.8 Haptics

Tactile = texture/roughness/temperature/vibration。  
Force = weight/inertia/resistance/torque。

## 5.9 Graphics pipeline

Application stage = CPU。  
Geometry stage = GPU transformations/shading/projection/clipping。  
Rasterizer stage = fragments/anti-aliasing/texture。

## 5.10 Bottlenecks

CPU 100% → application bottleneck。  
Reducing lights/polygons helps → geometry/transform bottleneck。  
Reducing resolution helps → rasterizer/fill bottleneck。

## 5.11 DVE

User partitioning simple but no cross-server interaction。  
Region partitioning spatial but fixed regions can overload。  
Dynamic partitioning adaptive but complex。

## 5.12 Presence

Increase：high visual quality, large FOV, low latency, head tracking, multiple senses, interactivity, body visibility。  
Decrease：sensory mismatch, high latency, poor interactivity, cables, low audio quality, no body visibility。

## 5.13 Modeling

Geometric / kinematical / physical / behavior / model management。  
LoD maintains frame rate by reducing detail when detail is not visible。  
Time-critical rendering = maximize quality within frame deadline。

## 5.14 Applications

Medical：safe repeated training, rare cases, virtual patients, haptics。  
Education：interactive simulation and 3D concepts。  
Military/aerospace：dangerous/expensive training safely。  
Manufacturing：virtual prototyping and assembly verification。  
Robotics/telepresence：remote control with visual/haptic feedback。
