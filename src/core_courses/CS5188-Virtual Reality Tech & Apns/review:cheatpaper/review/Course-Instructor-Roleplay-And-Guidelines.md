## 第2章：Input Devices (输入设备)

### 1. Basic of 3D Tracking (3D追踪基础)

- **追踪器 (Tracker)**: 一种用于实时测量物体位置和（或）方向的设备，常用于追踪用户的头部、手部和四肢 。
- **自由度 (DOFs)**: 指系统需要追踪的独立运动维度。例如2D鼠标是2 DOFs，加速度计（测位置）或陀螺仪（测方向）是3 DOFs，结合两者的手机是6 DOFs 。
- **坐标转换**: 3D物体点的位置通过一系列矩阵转换决定：依次经过模型矩阵($M_{world}$，局部到世界坐标)、视图矩阵($M_{view}$，世界到用户视点)和投影矩阵($M_{proj}$，视点到2D图像) 。
- **核心性能指标**:
  - **准确度 (Accuracy)**: 测量值与真实位置的相似度，离参考系原点越远，准确度越低 。
  - **抖动 (Jitter)**: 即使目标静止，追踪器输出的随机波动噪声 。
  - **漂移 (Drift)**: 误差随时间不断累积增加的现象，常需要次级追踪器进行重置 。
  - **延迟 (Latency)**: 运动发生到系统输出信号的迟滞时间。高延迟是引发“模拟晕动症”(Simulation sickness)的主要原因 。

### 2. Types of 3D Trackers (3D追踪器类型)

- **机械追踪器 (Mechanical Trackers)**: 基于外骨骼和传感器关节构建 。优点是精度高、延迟低、无视线遮挡问题；缺点是由于物理连接限制了绝对运动范围，设备重易疲劳，且会干扰用户动作 。
- **磁性追踪器 (Magnetic Trackers)**: 利用发射器产生磁场，接收器感知磁场变化来计算位置 。
  - **AC（交流）磁追踪器**: 磁场快速变化会在周围金属中产生“涡电流 (Eddy currents)”，引发新的干扰磁场，导致测量畸变 。
  - **DC（直流）磁追踪器**: 采用脉冲发射方式，中间留有停顿时间让涡电流消散，有效抵抗了非铁磁金属干扰，但仍受铁磁金属和铜影响 。
- **超声波追踪器 (Ultrasonic Trackers)**: 利用声波飞行时间测距 。便宜轻便、不受金属干扰；但存在视线遮挡问题，易受温度环境噪音影响，且更新率较低（需等待回声消退） 。
- **光学追踪器 (Optical Trackers)**: 基于相机和标记点 。
  - **Outside Looking In**: 外部相机拍摄用户身上的标记物 。
  - **Inside Looking Out**: 传感器在用户身上（如HiBall），标记在天花板等环境中 。
  - 优点是极高精度；缺点是若身体部位遮挡标记则无法追踪（Occlusion） 。
- **惯性追踪器 (Inertial Trackers)**: 包含测量角速度的陀螺仪和测量线加速度的加速度计 。无范围和遮挡限制，但积分运算会导致误差随时间快速累积（漂移现象） 。

### 3. Navigation & Gesture Devices (导航与手势设备)

- **3D导航与操作**: 如Logitech Magellan（测量手部施加的力和扭矩）和MicroScribe 3D（采用直接运动学计算笔尖坐标的六自由度探针） 。
- **手势检测设备**:
  - **Pinch Gloves**: 利用指尖导电纤维的物理接触来识别捏合动作 。
  - **5DT Data Gloves**: 使用光纤传感器，根据手指弯曲时光的折射逸散量测量弯曲角度 。
  - **Didjigloves**: 采用电容式弯曲传感器测量 。
  - **CyberGloves**: 依靠电阻应变片 (Strain gauges) 受拉伸/压缩时产生的电压差来精确测量关节角度 。

## 第3章：Output Devices (Graphical Displays) (输出设备：图形显示)

### 1. The Human Visual System (人类视觉系统)

- **视网膜生理结构**: 视杆细胞（Rods）负责夜间视觉；视锥细胞（Cones）分为L、M、S三种，负责颜色感知。人眼对光谱中部的绿光最敏感 。
- **视野 (FOV)**: 双眼水平总视野约为180°，中间有约120°的双眼重叠区，大脑依靠重叠区图像水平偏移来判断深度（立体视觉） 。
- **深度感知线索 (Depth Cues)**:
  - 近处依赖：双眼收敛 (Convergence)、晶状体调节 (Accommodation)、视差 (Disparity) 和运动视差 (Motion Parallax) 。
  - 远处依赖：遮挡、透视、大气雾化和表面纹理 。
- **视觉敏锐度**: 人眼可分辨约1角分的大小，真正的“视网膜级显示器”单眼需要高达9000x8100的分辨率 。

### 2. HMD Image Formation (头显成像原理)

- **光学放大**: HMD利用透镜将微小的屏幕图像放大成距用户较远的“虚像(Virtual image)”，以填充用户的视野 。
- **收敛-调节冲突**: 现实中，眼睛收敛角度和晶状体对焦距离是一致的。但在HMD中，眼睛要根据虚拟深度产生收敛，而晶状体却一直需要对焦在固定距离的屏幕面上，这种冲突是VR造成视觉疲劳的原因 。

### 3. Personal Graphics Displays (个人显示器)

- **头戴式显示器 (HMD)**: 包含VR头显和AR眼镜（如Hololens，集成了激光投影、深度相机和空间映射等技术） 。
- **手持显示器 (HHD)**: 用户可随时举起或放下的设备，如虚拟双筒望远镜（使用高分辨率LCOS微显示器） 。
- **裸眼3D显示器 (Autostereoscopic Displays)**:
  - **被动式**: 使用背光光栅将画面按列分配给左右眼，用户必须在固定区域内观看 。
  - **主动式**: 结合眼动追踪和物理步进电机动态调整棱镜遮罩位置，扩大最佳观看区域 。

### 4. Large-Volume Displays (大体积显示系统)

- **基于显示器**: 采用支持120Hz以上高刷新率的屏幕，配合红外同步的快门眼镜（Active glasses）交替遮挡左右眼 。
- **投影技术**: LCD投影仪色彩清晰但存在明显像素感；DLP投影仪利用DMD（数字微镜元件）微小偏转反光，对比度高、画面更平滑 。
- **多投影融合**: 如CAVE或PanoWall系统，利用多台投影阵列并结合矩阵查找表对画面重叠区(25%左右)进行亮度均匀化处理(Edge blending) 。偏振3D技术通过让左右眼镜片匹配不同投影仪的偏振光分离画面 。

## 第4章：Output Devices (Sound and Haptics) (输出设备：声音与触觉)

### 1. Sound Properties & 3D Sound (声音特性与3D音效)

- **听觉特征**: 声音通过介质传播，空气中声速约343m/s。耳廓（Pinna）收集反射声音，外耳道和听小骨放大声音 。人耳最敏感频率为3K-4KHz 。
- **空间定位线索 (Sound Localization)**:
  - **方位角**: 依靠双耳时间差 (ITD，声波到达双耳的时间差) 和双耳强度差 (IID，即高频声音的“头部阴影效应”) 。低频声音只能依靠ITD定位 。
  - **仰角**: 依靠耳廓的物理反射造成不同频率的放大与衰减，帮助分辨上下和解决“前后混淆”问题 。
- **头相关传输函数 (HRTF)**:
  - 代表输入声音到听觉神经之间的变换方程（类似于个人声纹） 。
  - 通过对音频与HRTF进行“卷积 (Convolution)”，可让普通立体声具有虚拟3D空间感 。使用他人的HRTF会导致定位错误率上升 。

### 2. Haptic Feedback (触觉反馈机制)

- **触觉传感器机制**:
  - 慢适应受体（Merkel, Ruffini）：感知稳态压力和低频刺激（0-10Hz） 。
  - 快适应受体（Meissner, Pacinian）：感知变化力、振动和高频刺激（50-300Hz） 。
  - 本体感觉（Proprioception）：感知关节角度，肩髋分辨率高于手指 。
- **纯触觉接口 (Tactile Feedback)**:
  - 仅传递皮肤层面的震动或温度感觉，不提供物理阻力 。
  - 设备如增加震动电机的CyberTouch手套，或基于半导体热泵系统传递导热冷暖感的温度反馈手套 。
- **力反馈接口 (Force Feedback)**:
  - 通过机械结构传递物体的重量、硬度和运动惯性，主动抵抗用户动作 。
  - 设备包括力反馈摇杆、桌面级高精度PHANTOM机械臂，以及重量可达539g的CyberGrasp外骨骼手套 。

## 第5章：Computing Architectures for VR (VR计算架构)

### 1. The Graphic Rendering Pipeline (图形渲染流水线)

- **应用阶段 (CPU负责)**: 接收输入设备数据，更新虚拟世界状态与对象位置，并将相关几何体发送到下一步 。
- **几何阶段 (GPU负责)**: 涉及模型及视图坐标转换、计算表面光照（如Phong模型）。其中多边形着色模式分为Flat（全表面同色）、Gouraud（顶点颜色插值）和Phong（顶点法线插值计算） 。
- **光栅化阶段 (GPU负责)**: 将2D多边形转化为像素片段。包括纹理映射、Z-buffer深度测试与子像素颜色均值化处理（抗锯齿 Anti-aliasing） 。采用双缓冲(Double buffering)技术交替画面以消除闪烁 。
- **管线瓶颈**: CPU满载称为Application-limited；降低多边形数可提速称为Geometry-limited；降低分辨率可提速称为Rasterizer-limited (Fill-limited) 。

### 2. GPU架构与分布式集群

- **GPU特性**: 相比CPU，GPU没有复杂的逻辑控制，但拥有大量并行计算单元（如CUDA核心），极其适合高并发的数据吞吐（如像素级处理） 。
- **PC集群 (PC Clusters)**:
  - 为了驱动多投影仪的高分辨率“显示墙”，受限于单台主机的PCIe总线和接口限制，多采用PC集群系统（如Stanford的Chromium） 。
  - 利用WireGL等网络软件，将空间排序后的几何数据包直接分发到对应显示区域的渲染节点上 。
- **同步机制**: 对于分布式图形流水线，不仅要在软件层面同步命令，还要对显卡缓冲刷新(Buffer swap)和底层视频信号输出（Video synchronization）进行“主从同步”，防止画面撕裂 。触觉渲染管线(1000Hz)需与图形管线(60Hz)异步解耦运行 。
